# 3d-decoration-asset

Crea mascotte che seguono il cursore, oggetti a 360° guidati dallo scroll, clip in loop e modelli GLB, con la generazione in cloud su Runware solo dopo l'approvazione del costo.

Fa parte della [Prompt Library di CH Labs](https://www.cryptohelvetia.com/ch-labs/prompt-library), dove la pagina di riferimento è [3D decoration asset](https://www.cryptohelvetia.com/ch-labs/prompt-library/skills/3d-decoration-asset). Il repo contiene una copia della skill, rigenerata a ogni aggiornamento della libreria.

## Installare

In Claude Code aggiungi una volta il marketplace e installa il plugin.

```
/plugin marketplace add MicheDada21/ch-labs-skills
/plugin install 3d-decoration-asset@ch-labs-skills
```

Da shell i comandi sono `claude plugin marketplace add MicheDada21/ch-labs-skills` e `claude plugin install 3d-decoration-asset@ch-labs-skills`. Nell'app desktop premi + accanto al campo del prompt, apri Plugins, aggiungi il marketplace `MicheDada21/ch-labs-skills` con Add marketplace e poi il plugin con Add plugin.

Per avere tutte le skill della libreria installa `tutte-le-skill@ch-labs-skills`. Con altri agenti copia la cartella `skills/3d-decoration-asset` tra le skill dell'agente, per esempio in `~/.codex/skills/3d-decoration-asset`.

## Requisiti

La generazione in cloud usa una chiave [Runware](https://runware.ai).
